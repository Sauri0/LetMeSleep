- **Atkinson Hyperlegible Regular y Bold**, Braille Institute of America, Inc., copyright 2020. Fuente de lectura para controles, datos y ayudas. [Origen](https://github.com/google/fonts/tree/main/ofl/atkinsonhyperlegible). Archivo `AtkinsonHyperlegible/OFL.txt`: SIL Open Font License 1.1.

Se incluyen los avisos de copyright y licencias originales completos junto a cada familia. Las fuentes se redistribuyen integradas al juego; no se venden por separado. La licencia de las fuentes no reemplaza la licencia del código del juego.

Para la entrega Windows, conservar ambos archivos OFL como avisos legibles en la carpeta de licencias del paquete, además de los recursos incluidos en el juego.
