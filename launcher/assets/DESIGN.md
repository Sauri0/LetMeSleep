# Identidad del launcher 1.0.1

Asset final: `launcher-logo.png`. Generado con la herramienta integrada image_gen el 2026-09-12, copiado al repositorio desde la salida original. `launcher.ico` es la conversión de formato para Windows, con siete resoluciones, reproducible con `work/make-launcher-icon.ps1` (sin redibujar el arte).

Prompt final usado:

> Create a production app icon for the Windows launcher of the multiplayer comedy game 'Let me sleep'. Use case logo-brand. One square icon, centered emblem, transparent background beyond a rounded dark midnight-navy tile. A mischievous stylized mosquito with a long slim abdomen, two thin pale teal wings and a clearly readable long proboscis, wearing a small floppy yellow nightcap; expressive half-lidded skeptical eyes, comic adult-friendly humor, not infantile, not Disney. Simplified bold flat cartoon shapes, heavy dark contours, restrained cream / golden yellow / teal palette. Clear readable silhouette at 32 pixels, centered with generous safe margin, crisp polished graphic with subtle cel shading, no tiny details, no text, no letters, no watermark. This is an executable icon and launcher brand asset, not concept art or a UI screenshot.

La interfaz utiliza la misma paleta, un lateral de marca, una columna de acciones, un campo de ubicación legible y un único botón principal amarillo. El logo está incrustado: no hay archivos gráficos adicionales que deba descargar el jugador.
