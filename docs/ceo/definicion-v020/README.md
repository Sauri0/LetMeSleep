# Cuestionario de definición v0.2.0

Abrir index.html en un navegador. Funciona sin servicios externos. Incluye 150 preguntas, 450 opciones, notas propias, delegación explícita, búsqueda, filtros, ruta inicial de 20 decisiones y cuatro comparativas visuales.

No hay opciones premarcadas. Se guarda localmente cuando el navegador lo permite. Exportar Markdown para lectura o JSON para conservar/importar respuestas; compartir el archivo en la tarea para que CEO lo procese. La página no envía nada automáticamente ni cambia código o decisiones del proyecto.

CUESTIONARIO-COMPLETO.md contiene toda la lista. RESPUESTAS-PLANTILLA.md permite responder por ID en el chat. Las fuentes de data/ son entradas de trabajo; index.html contiene una copia embebida para uso sin servidor.

Las imágenes de visuales/ son bocetos exploratorios generados con imagegen, no assets del juego ni trabajos Higgsfield. Los wireframes de HUD/cámara están hechos en HTML/SVG para comparar composición. No implican aprobación de arte ni cambios a la geografía existente.

Los acuerdos previos se conservan. Elegir una alternativa incompatible con otra pregunta requiere resolver el conflicto al consolidar; no se ejecutan cambios por una selección aislada. Tras recibir respuestas, producir una especificación versionada y matriz de aceptación, documentando pendientes y delegaciones.
